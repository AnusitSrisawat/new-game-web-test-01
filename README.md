# Cozy 2D MMORPG (เกม MMORPG 2D บนเว็บ)

เกม 2D MMORPG สไตล์ Classic (แรงบันดาลใจจาก Ragnarok Online / ECO) เล่นบนเบราว์เซอร์ มีมัลติเพลเยอร์ซิงค์สดผ่าน WebSocket

## วิธีรัน
```bash
npm install
npm start        # เปิด http://localhost:3000 (เปลี่ยนพอร์ตด้วย PORT=xxxx)
```

## การควบคุม
- `WASD` เดิน (ใช้ได้ทุกภาษาแป้นพิมพ์) · `Enter` เปิดช่องแชทเพื่อพิมพ์ / `Enter` อีกครั้งเพื่อส่งและกลับไปเดิน · `Esc` ยกเลิกพิมพ์ · คลิกขวา ล็อคเป้าหมาย · คลิกซ้าย โจมตี · `1-9` สกิล
- ปุ่ม ⚙ Option มุมขวาบนรวมเมนูทั้งหมด · ปุ่มลัด: `C` สเตตัส · `I` กระเป๋า · `P` ปาร์ตี้ · `J` เควสต์ · `T` สมุดสมบัติ · `K` ร้าน/กาชา · `M` แผนที่

## ฟีเจอร์ที่มีในเกมตอนนี้
- **ไม่มีอาชีพ**: ความเก่งมาจากสเตตัส + อาวุธที่ถือ (สกิลจะมาทีหลัง)
  - สเตตัส 6 ตัว: STR (ประชิด) / AGI (ความเร็ว) / VIT (HP, DEF) / DEX (ธนู) / INT (คฑา) / LUK (คริ) — ได้ 4 แต้มต่อเลเวล
  - ระยะโจมตีตามอาวุธ: มือเปล่า 55 · กิ่งไม้ 75 · ดาบ 80 · ธนู 260 · คฑา 230 (ธนู/คฑายิงกระสุนได้ไกล)
  - เริ่มต้นด้วย **กิ่งไม้** ไม่มีสกิล; แถบสกิล 1-9 ว่างให้ผู้เล่นตั้งเอง (ยังไม่มีสกิลให้ใส่)
  - เลเวลใช้เป็นเงื่อนไขสวมอาวุธ/เกราะหายาก (เช่น ดาบมังกร ต้อง Lv.75)
- **9 แผนที่** (ตอนนี้เป็นพื้นเรียบ + กริด 32px ไว้เติมของทีหลัง): Central Town (โซนปลอดภัย), Green Meadows, Misty Forest, Bandit Hideout, Goblin Caverns, Lava Volcano, Bone Crypt, Haunted Ruins, Dragon's Lair — แมพละ 4 ชนิดมอนสเตอร์ (Haunted Ruins มี 2 ชนิดเพราะมอนสเตอร์เหลือแค่นี้)
- **มอนสเตอร์** server คุมทั้งหมด: เดินเล่น/ไล่ผู้เล่น/โจมตี ทุกคนเห็นเหมือนกัน แย่งกันตีได้ (คนฆ่าได้รางวัล) รีสปอนอัตโนมัติ
- **ไอเทม**: อาวุธ กิ่งไม้/ดาบ/ธนู/คฑา, เกราะ, ยา HP, วัตถุดิบดรอป
- **คราฟต์ไอเทม** จากวัตถุดิบที่ดรอป
- **สมุดสมบัติ (Relics)**: สมบัติในตำนานดรอปจากมอนสเตอร์/บอส ให้โบนัสถาวร
- **เควสต์** พร้อมตัวติดตามเควสต์บน HUD
- **ร้านค้า & กาชา** (Gold / Token)
- **Auto Hunt**: ตั้งระยะ (ช่อง), เลือกมอนสเตอร์ที่จะตี, ใช้ยา HP อัตโนมัติ (% และชนิดยา) · ช่องยา HP ด่วน (ปุ่ม Q)
- **ปาร์ตี้** สูงสุด 6 คน: สร้าง/เชิญ/ออก, เปลี่ยนหัวหน้า, เปลี่ยนชื่อ, เตะสมาชิก, ประกาศคนเข้า-ออกในแชท
  - ตั้งค่าได้: หาร EXP (+25% โบนัส, เฉพาะคนที่อยู่แมพเดียวกัน) หรือ ใครฆ่าคนนั้นได้ / รับสมาชิกอัตโนมัติ / เงื่อนไขเลเวล
  - แยกแท็บ "สร้างปาร์ตี้" / "ค้นหาปาร์ตี้" — ค้นหากรองตามเลเวลหัวหน้าและแมพ, ขอเข้าร่วมแล้วหัวหน้าอนุมัติ
- **มัลติเพลเยอร์**: เห็นผู้เล่นอื่นแบบเรียลไทม์ พร้อมอนิเมชันเดิน/โจมตี/สกิล
- **ซูมเข้า/ออก**: ล้อเมาส์ (หรือปุ่ม +/- ข้างมินิแมพ / คีย์ + -) ซูมออกได้ไม่เกินขอบแมพ จำค่าไว้ · ทุกแมพเข้าได้ทุกเลเวล · ตัวละครใหม่ได้ชื่อสุ่มชั่วคราว (ยังไม่มีระบบล็อกอิน)
- **คลิกเควสต์** (ในแผงซ้ายหรือหน้าต่างเควสต์) → ถามยืนยันแล้วพาไปแมพที่มีมอนสเตอร์เป้าหมาย
- **หน้าต่างลอยหลายบาน**: เปิดค้างไว้พร้อมกันได้ ลากย้ายได้ จำตำแหน่งและหน้าต่างที่เปิดไว้ (Esc ปิดบานบนสุด) ส่วนแผงปาร์ตี้/เควสต์ซ้ายบนพับเก็บได้
- **แชท** แยกแท็บ (รวม / ระบบ / ดรอป / สมบัติ) และย่อเหลือแค่ไอคอน 💬 ได้ (มีตัวเลขข้อความที่ยังไม่อ่าน)
- **มินิแมพ**, เสียงเอฟเฟกต์ (เปิด/ปิดได้), เซฟข้อมูลผู้เล่นใน localStorage

## ยังไม่ได้ทำ (ดู `GAME_SPEC.md` และ `PLAN.md`)
- ระบบตีบวก +1 ถึง +10 (มีแค่ตารางข้อมูล)
- ระบบจับสัตว์เลี้ยง / Pet (มีแค่ตารางข้อมูล)
- ระบบบัญชี/ฐานข้อมูล, ตรวจโกงเต็มรูปแบบ (สเตตัสยังอยู่ที่ client)
- ระบบสกิลแบบสุ่มด้วยเงิน + ตั้งสกิลลงแถบ 1-9 (ยังไม่มีสกิลเลย) — ดูแผนใน `PLAN.md`

## Studio (`/studio`) — เครื่องมือ dev แก้ข้อมูลเกม
- รัน `npm start` แล้วดู token ใน terminal (หรือกำหนดเองด้วย `STUDIO_TOKEN=xxxx npm start`) จากนั้นเปิด `http://localhost:3000/studio`
- แก้ได้: **แมพ** (ชื่อ/คำอธิบาย/เลเวลปลดล็อก/ขนาดจัตุรัส/สี/**texture พื้น** 9 แบบ), **วางออบเจกต์** (แท็บ 🌳: คลิกวาง ลากย้าย ปรับขนาด ติ๊ก "ชนได้" — ต้นไม้ บ้าน หิน ฯลฯ), **หน้าจอ UI** (สีธีม HUD + ซ่อน/แสดงมินิแมพ แชท แผงปาร์ตี้ ปุ่มซูม), **มอนสเตอร์** (ชื่อ เลเวล HP ATK DEF EXP + พฤติกรรม ความเร็ว ระยะเห็น ระยะโจมตี ฯลฯ), **การเกิดของมอนสเตอร์** (ชนิด/จำนวน/เวลาเกิดใหม่ต่อแมพ), **ไอเทม**, **เควสต์**, **สกิล** (จดรายชื่อไว้ก่อน ยังไม่ผูกกับเกม)
- กดบันทึก → เขียนไฟล์ `data/overrides.json` + `data/spawns.json` (สำรองไฟล์เก่าไว้ใน `data/backups/` 20 ชุดล่าสุด) แล้วผู้เล่นที่ออนไลน์จะโหลดเกมใหม่เอง
- ค่าตั้งต้นยังอยู่ใน `src/data.js` / `src/maps.js` ; Studio เก็บเฉพาะ "ส่วนที่แก้" ซ้อนทับ (ปุ่ม ↺ คืนค่าเดิมต่อช่อง)
- ปิด Studio บน production: ตั้ง `NODE_ENV=production` (จะเปิดได้ก็ต่อเมื่อกำหนด `STUDIO_TOKEN` เอง)
- ข้อจำกัด: ออบเจกต์ที่ "ชนได้" กันเฉพาะผู้เล่น (มอนสเตอร์ยังเดินผ่านได้) ; UI ยังย้ายตำแหน่งแผงไม่ได้ ; ผูกสกิลยังไม่ได้ (รอระบบสกิล)

## รูปมอนสเตอร์/ไอเทม และดรอป
- รูปต้นฉบับเป็นแผ่น (sheet) ใน `assets/` และ `assets/items/` ; รันสคริปต์ตัดพื้นหลังเป็น PNG โปร่งใสต่อรูปที่ `assets/sprites/` ด้วย
  `node tools/export-manifest.mjs > /tmp/manifest.json && python3 tools/cutout.py /tmp/manifest.json` (ต้องมี Python + Pillow + numpy) — เพิ่มรูปใหม่ใน `src/sprites.js` แล้วรันซ้ำ
- มอนสเตอร์ 1 ตัวดรอปได้หลายแบบ (ตอนนี้ 3 แบบ: 70% / 40% / 10%) — แก้ **ชนิดไอเทม, % และเพิ่ม/ลบ** ได้ใน Studio แท็บ "มอนสเตอร์" (เก็บใน `data/overrides.json` ส่วน `drops`)
- ตอนนี้ในเกมมีไอเทมแค่: กิ่งไม้ (อาวุธเริ่มต้น), ยา HP, และไอเทมที่มอนสเตอร์ดรอป — ไอเทม/อาวุธ/เกราะ/วัตถุดิบเก่า, ดรอป Relic และสูตรคราฟต์ถูกปิดไว้ก่อน (ข้อมูลยังอยู่ใน `src/data.js`; รายการที่เปิดอยู่ดูที่ `pruneItems` ใน `src/catalog.js`)
