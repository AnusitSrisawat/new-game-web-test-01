# Cozy 2D MMORPG (เกม MMORPG 2D บนเว็บ)

เกม 2D MMORPG สไตล์ Classic (แรงบันดาลใจจาก Ragnarok Online / ECO) เล่นบนเบราว์เซอร์ มีมัลติเพลเยอร์ซิงค์สดผ่าน WebSocket

## วิธีรัน
```bash
npm install
npm start        # เปิด http://localhost:3000 (เปลี่ยนพอร์ตด้วย PORT=xxxx)
```

## การควบคุม
- `WASD` เดิน · คลิกขวา ล็อคเป้าหมาย · คลิกซ้าย โจมตี · `1-9` สกิล
- ปุ่ม ⚙ Option มุมขวาบนรวมเมนูทั้งหมด · ปุ่มลัด: `C` สเตตัส · `I` กระเป๋า · `P` ปาร์ตี้ · `J` เควสต์ · `T` สมุดสมบัติ · `K` ร้าน/กาชา · `M` แผนที่

## ฟีเจอร์ที่มีในเกมตอนนี้
- **ไม่มีอาชีพ**: ความเก่งมาจากสเตตัส + อาวุธที่ถือ (สกิลจะมาทีหลัง)
  - สเตตัส 6 ตัว: STR (ประชิด) / AGI (ความเร็ว) / VIT (HP, DEF) / DEX (ธนู) / INT (คฑา) / LUK (คริ) — ได้ 4 แต้มต่อเลเวล
  - ระยะโจมตีตามอาวุธ: มือเปล่า 55 · กิ่งไม้ 75 · ดาบ 80 · ธนู 260 · คฑา 230 (ธนู/คฑายิงกระสุนได้ไกล)
  - เริ่มต้นด้วย **กิ่งไม้** ไม่มีสกิล; แถบสกิล 1-9 ว่างให้ผู้เล่นตั้งเอง (ยังไม่มีสกิลให้ใส่)
  - เลเวลใช้เป็นเงื่อนไขสวมอาวุธ/เกราะหายาก (เช่น ดาบมังกร ต้อง Lv.75)
- **6 แผนที่** (ตอนนี้เป็นพื้นเรียบ + กริด 32px ไว้เติมของทีหลัง): Central Town (โซนปลอดภัย), Green Meadows, Misty Forest, Goblin Caverns, Lava Volcano, Dragon's Lair
- **มอนสเตอร์** server คุมทั้งหมด: เดินเล่น/ไล่ผู้เล่น/โจมตี ทุกคนเห็นเหมือนกัน แย่งกันตีได้ (คนฆ่าได้รางวัล) รีสปอนอัตโนมัติ
- **World Boss Raid**: Ancient Red Dragon MVP (Lv.99, HP 50,000) พร้อมวงเตือนโจมตี (Telegraphed AoE) ให้เดินหลบ
- **ไอเทม**: อาวุธ กิ่งไม้/ดาบ/ธนู/คฑา, เกราะ, ยา HP, วัตถุดิบดรอป, ไอเทม MVP
- **คราฟต์ไอเทม** จากวัตถุดิบที่ดรอป
- **สมุดสมบัติ (Relics)**: สมบัติในตำนานดรอปจากมอนสเตอร์/บอส ให้โบนัสถาวร
- **เควสต์** พร้อมตัวติดตามเควสต์บน HUD
- **ร้านค้า & กาชา** (Gold / Token)
- **Auto Hunt**: ตั้งระยะ (ช่อง), เลือกมอนสเตอร์ที่จะตี, ใช้ยา HP อัตโนมัติ (% และชนิดยา) · ช่องยา HP ด่วน (ปุ่ม Q)
- **ปาร์ตี้** สูงสุด 6 คน: สร้าง/เชิญ/ออก, เปลี่ยนหัวหน้า, เปลี่ยนชื่อ, เตะสมาชิก, ประกาศคนเข้า-ออกในแชท
  - ตั้งค่าได้: หาร EXP (+25% โบนัส, เฉพาะคนที่อยู่แมพเดียวกัน) หรือ ใครฆ่าคนนั้นได้ / รับสมาชิกอัตโนมัติ / เงื่อนไขเลเวล
  - แยกแท็บ "สร้างปาร์ตี้" / "ค้นหาปาร์ตี้" — ค้นหากรองตามเลเวลหัวหน้าและแมพ, ขอเข้าร่วมแล้วหัวหน้าอนุมัติ
- **มัลติเพลเยอร์**: เห็นผู้เล่นอื่นแบบเรียลไทม์ พร้อมอนิเมชันเดิน/โจมตี/สกิล
- **แชท** แยกแท็บ (รวม / ระบบ / ดรอป / สมบัติ) และย่อเหลือแค่ไอคอน 💬 ได้ (มีตัวเลขข้อความที่ยังไม่อ่าน)
- **มินิแมพ**, เสียงเอฟเฟกต์ (เปิด/ปิดได้), เซฟข้อมูลผู้เล่นใน localStorage

## ยังไม่ได้ทำ (ดู `GAME_SPEC.md` และ `PLAN.md`)
- ระบบตีบวก +1 ถึง +10 (มีแค่ตารางข้อมูล)
- ระบบจับสัตว์เลี้ยง / Pet (มีแค่ตารางข้อมูล)
- ระบบบัญชี/ฐานข้อมูล, ตรวจโกงเต็มรูปแบบ (สเตตัสยังอยู่ที่ client)
- ระบบสกิลแบบสุ่มด้วยเงิน + ตั้งสกิลลงแถบ 1-9 (ยังไม่มีสกิลเลย) — ดูแผนใน `PLAN.md`
