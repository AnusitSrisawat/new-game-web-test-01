## 1. สเตตัสของผู้เล่น

เริ่มต้นทุกตัว = **5** (STR AGI VIT DEX INT LUK) · ได้ **4 แต้ม/เลเวล** · ใส่แต้มทีละ 1 (ไม่มีค่าใช้แต้มเพิ่ม ไม่มีเพดาน)
📁 แต้มต่อเลเวล: `statPoints += 4` ใน `Player.gainExp()` · ค่าเริ่มต้น 5: `this.stats` ใน constructor

| สเตตัส | ผลที่ได้จริงในโค้ด |
|---|---|
| **STR** | ATK **×3** เมื่อถืออาวุธระยะประชิด (มือเปล่า/กิ่งไม้/ดาบ) · เป็นค่า "รอง" (+1 ต่อแต้ม) ของธนู |
| **DEX** | ATK **×3** เมื่อถือ**ธนู** · เป็นค่า "รอง" (+1 ต่อแต้ม) ของอาวุธประชิด/คฑา |
| **INT** | ATK **×3** เมื่อถือ**คฑา** (ยังไม่มีคฑาเป็นไอเทมในเกมตอนนี้) |
| **VIT** | Max HP **+18** ต่อแต้ม และ DEF **+1.5** ต่อแต้ม |
| **AGI** | ASPD **+0.015** ต่อแต้ม (ความเร็วโจมตี) · ความเร็วเดิน **+0.3%** ต่อแต้ม (สูงสุด +40%) — `moveMul` ใน `src/player.js` |
| **LUK** | โอกาสคริติคอล **+0.5%** ต่อแต้ม |

ค่าคงที่พื้นฐาน (ทุกคนเริ่มจากนี้): 📁 `BASE_STATS` ใน `src/data.js`

| ค่า | เริ่มต้น |
|---|---|
| HP | 150 |
| ATK | 12 |
| DEF | 5 |
| ASPD | 1.0 |

## 2. ค่าที่คำนวณได้ (Derived stats)

"อาวุธหลัก" = สเตตัสที่อาวุธที่ถืออยู่ใช้คำนวณ (`scalesWith` ของประเภทอาวุธ ดูหัวข้อ 4)
"รอง" = DEX ถ้าอาวุธหลักเป็น STR/INT, หรือ STR ถ้าอาวุธหลักเป็น DEX

```
Max HP = 150 + (เลเวล × 25) + (VIT × 18) + HP ของเกราะ + HP จาก Relic
ATK    = 12 + (สเตตัสหลัก × 3) + สเตตัสรอง + floor(เลเวล × 1.5)
         + ATK ของอาวุธ + ATK ของเกราะ + ATK จาก Relic
         (× 1.05 ถ้าใส่ costume_angel_wings แล้วปัดลง)
DEF    = 5 + (VIT × 1.5) + DEF ของอาวุธ + DEF ของเกราะ + DEF จาก Relic   (ปัดลง)
ASPD   = 1.0 + (AGI × 0.015) + ASPD จาก Relic (+0.08 ถ้าใส่ costume_celestial_blade)
Crit   = 5% + (LUK × 0.5%) + Crit จาก Relic        (สูงสุด 75%)
```

📁 ทั้งหมดอยู่ใน `src/player.js` getter ชื่อเดียวกัน · ค่าของไอเทม (atk/def/hp) อยู่ที่ตัวไอเทมใน `src/data.js` ✏️ (Studio แท็บไอเทม)

**ตัวอย่าง** ตัวละครใหม่ (Lv.1 ทุกสเตตัส 5 ถือกิ่งไม้ ATK+3):
ATK = 12 + 5×3 + 5 + 1 + 3 = **36** · DEF = 5 + 7.5 = **12** · HP = 150 + 25 + 90 = **265** · ASPD **1.07** · Crit **7.5%**

**ตัวอย่าง** Lv.10, STR 20, DEX 8, VIT 10, ถือ Iron Broadsword (ATK 25, DEF 5):
ATK = 12 + 60 + 8 + 15 + 25 = **120** · DEF = 5 + 15 + 5 = **25** · HP = 150 + 250 + 180 = **580**

## 3. เลเวลและ EXP

```
EXP ที่ต้องใช้เลื่อนจากเลเวล L → L+1  =  floor( 60 × L^1.5  +  L × 25 )
```
📁 `Player.maxBaseExp` ใน `src/player.js` · อัปเลเวลแล้ว **HP เต็ม** และได้ 4 แต้มสเตตัส (EXP ส่วนเกินทบต่อ อัปหลายเลเวลต่อกันได้)

| เลเวล | 1 | 2 | 5 | 10 | 20 | 30 | 40 | 50 | 60 | 75 | 100 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| EXP ถึงเลเวลถัดไป | 85 | 219 | 795 | 2,147 | 5,866 | 10,609 | 16,178 | 22,463 | 29,385 | 40,846 | 62,500 |

- เลเวลใช้เป็น**เงื่อนไขสวมอุปกรณ์** (`reqLevel` ของไอเทม ✏️) — ตอนนี้เปิดโหมดเทส `TEST_ALL_SWORDS = true` ใน `src/player.js` จึงสวมได้ทุกเลเวล
- ไม่มีเพดานเลเวล

## 5. ดาเมจที่ผู้เล่นตีมอนสเตอร์

📁 `performPlayerAttack()` ใน `src/game.js`

```
crit?    = สุ่ม ≤ Crit%
ดาเมจ    = max(1, ATK ผู้เล่น − DEF มอนสเตอร์)          ← หักแบบ "ลบตรงๆ" ไม่ใช่เปอร์เซ็นต์
ดาเมจ    = floor( ดาเมจ × สุ่ม 0.90 ถึง 1.10 )
ถ้า crit = floor( ดาเมจ × 1.6 )
```

- **ความเร็วโจมตี** เมื่อกด Auto หรือเดินเข้าหาเป้าหมายที่ล็อกไว้: `cooldown = 1.0 / ASPD` วินาที
- ธนู/คฑา: สร้างกระสุนบินไปหาเป้า (ความเร็วกระสุน 750 px/วิ) ดาเมจคำนวณตอนยิง
- ท่าฟัน 3 จังหวะ (combo) ความยาวท่า `ATTACK_ANIM = 0.34` วินาที — เป็นแค่ภาพ ไม่กระทบดาเมจ

**ตัวอย่าง** ATK 120 ตี forest_wolf (DEF 20) → 100 ± 10% = **90–110** · ถ้าคริ = **144–176**

### เพดานที่ server ตรวจ (กันโกง) 📁 `server.js`
| กติกา | ค่า |
|---|---|
| ดาเมจสูงสุดต่อการตี 1 ครั้ง | `500 + เลเวล × 60` (ถ้าเกินจะถูกตัดเหลือเท่านี้) |
| ผู้เล่นต้องอยู่ห่างมอนสเตอร์ไม่เกิน | 700 px และอยู่แมพเดียวกัน |
| จำนวนการตีต่อวินาที (ต่อเนื่อง) | 14 ครั้ง/วิ (สะสมได้ 24 ครั้ง) |
| แชท | 1 ข้อความ/วิ (สะสมได้ 5) ยาวไม่เกิน 200 ตัวอักษร |

## 6. ดาเมจที่มอนสเตอร์ตีผู้เล่น

📁 ลูป AI ใน `server.js` (หา `monster_attack`)

```
ดาเมจ = max(1, floor( (ATK มอนสเตอร์ − DEF ผู้เล่น) × สุ่ม 0.90–1.10 ))
```
- ATK มอนสเตอร์ = `atk` ของ template ✏️ · DEF ผู้เล่น = ค่า DEF ที่ client รายงานมา (อัปเดตทุก 1.5 วิ)
- ตายแล้ว: HP เหลือ 60% ของ Max HP แล้ววาร์ปกลับเมือง (`applyMonsterDamage` ใน `src/game.js`)

**ตัวอย่าง** forest_wolf (ATK 42) ตีผู้เล่น DEF 25 → 17 ± 10% = **15–18**

### พฤติกรรมมอนสเตอร์ (AI) ✏️ Studio แท็บมอนสเตอร์ → "พฤติกรรม"
ค่าตั้งต้น 📁 `MONSTER_AI_DEFAULT` / รายตัว `MONSTER_AI` ใน `src/data.js`

| ค่า | ความหมาย | ตั้งต้น |
|---|---|---|
| speed | ความเร็ว px/วิ (0 = ไม่เดิน) | 60 |
| aggro | เห็นผู้เล่นในระยะนี้แล้วไล่ (0 = ไม่ไล่) | 200 |
| attackRange | ตีได้เมื่ออยู่ใกล้ขนาดนี้ | 60 |
| attackCooldown | วินาทีระหว่างตี (สุ่ม ±10%) | 1.6 |
| leash | ไล่ห่างจุดเกิดเกินนี้แล้วเลิกไล่ | 650 |
| wanderRadius | เดินเล่นรอบจุดเกิดในรัศมีนี้ | 140 |

กฎ: มอนสเตอร์**ไล่คนที่ตีมันล่าสุด** (แย่งกันตีได้) · ไม่มีคนในระยะก็เดินกลับจุดเกิด/เดินเล่น (ความเร็วเดินเล่น = ครึ่งหนึ่งของ speed)

## 7. รางวัลเมื่อฆ่ามอนสเตอร์

📁 `rewardKill()` ใน `server.js`

| รางวัล | สูตร | แก้ได้ที่ |
|---|---|---|
| **EXP** | `exp` ของมอนสเตอร์ (ค่าตายตัว ไม่ขึ้นกับเลเวลผู้เล่น) | ✏️ มอนสเตอร์ → EXP |
| **ทอง** | `5 + (เลเวลมอนสเตอร์ × 2)` | 📁 `monsterGold()` ใน `server.js` |
| **ไอเทม** | สุ่มทีละช่องของตารางดรอป: ได้ถ้า `สุ่ม 0–1 ≤ chance` (ทุกช่องสุ่มแยกกัน ได้หลายชิ้นพร้อมกันได้) | ✏️ มอนสเตอร์ → ไอเทมที่ดรอป |

- ดรอปมาตรฐาน 3 ช่อง: **70% / 40% / 10%** (`CHANCES` ใน `src/catalog.js`)
- **ปาร์ตี้**: ถ้าตั้ง "หาร EXP" และมีสมาชิกอยู่แมพเดียวกันมากกว่า 1 คน → ทุกคน (รวมคนฆ่า) ได้ `EXP × 1.25 ÷ จำนวนคน` (ทองก็หารเหมือนกัน) · ถ้าตั้ง "ใครฆ่าคนนั้นได้" → คนฆ่าได้เต็ม ไม่มีโบนัส (`PARTY_EXP_BONUS = 1.25` ใน `server.js`)
- คนที่ฆ่า (ตีตัวสุดท้าย) เป็นคนได้ดรอปไอเทม

HP  = round( 0.135 × lv^2.5 + 10×lv + 20 )
ATK = round( 3 + 1.6×lv + 0.012×lv² )

## 11. ตารางแก้ไขเร็ว — "อยากเปลี่ยน X ต้องไปแก้ที่ไหน"

| อยากเปลี่ยน | แก้ที่ |
|---|---|
| ค่าเริ่มต้น HP/ATK/DEF/ASPD ของทุกคน | `BASE_STATS` — `src/data.js` |

## 12. ข้อสังเกต / สิ่งที่ยังไม่สมบูรณ์ (รู้ไว้เวลาปรับสมดุล)

1. **ตีด้วยการคลิกซ้ายไม่มีคูลดาวน์** — คูลดาวน์ `1/ASPD` ใช้เฉพาะตอน Auto/เดินเข้าหาเป้าที่ล็อก การคลิกซ้ายรัวถูกจำกัดแค่เพดาน 14 ครั้ง/วิของ server ⇒ **AGI/ASPD ไม่มีผลกับการคลิกมือ** (ควรแก้ถ้าจะให้ AGI สำคัญ)
2. **ดรอปไอเทมสุ่มที่ client** — server ยังไม่ควบคุมว่าได้ของอะไร (โกงได้)
3. **ATK/DEF/HP ของผู้เล่นคำนวณที่ client** — server เชื่อค่า DEF ที่ client รายงาน และตัดดาเมจแค่ตามเพดานต่อครั้ง ถ้าจะกันโกงจริงต้องย้ายสูตรตัวละครไป server (ดู `PLAN.md`)
4. **DEF หักแบบลบตรงๆ** — ถ้า DEF ผู้เล่น ≥ ATK มอนสเตอร์ ดาเมจจะเหลือ 1 เสมอ (ไม่มีเพดาน DEF) และถ้า ATK ผู้เล่น ≤ DEF มอนสเตอร์ ก็ตีได้แค่ 1 — ตอนปรับสมดุลดูตาราง ATK/DEF ในหัวข้อ 8 ประกอบ
5. **INT/คฑายังไม่มีใช้** — มีสูตรไว้แล้วแต่ยังไม่มีอาวุธคฑาให้ถือในเกม · SP และสกิล **มีในเกมแล้ว** (MaxSP = (30 + Lv×2 + INT×4) × (1+Max SP%), ฟื้น 1+INT×0.1/วิ; ATK/DEF/HP/ASPD/Crit/เดิน คูณโบนัสจากสกิล Passive ที่ใส่ช่อง + บัฟที่ทำงานอยู่) — สเปกและข้อมูลสกิลอยู่ที่ [`SKILLS.md`](SKILLS.md)** (Active/Passive, สมุดสกิลจากกาชา, สูตรดาเมจ/SP)
6. **เควสต์**: รางวัลอยู่ที่ตัวเควสต์ (`rewardGold/rewardExp/rewardTokens`) ✏️ — รูปแบบเควสต์ดู `QUEST_PATTERN.md`
