# ✨ ระบบสกิล (Skill System) — สเปก

> **สถานะ: ข้อมูลล่วงหน้า (draft)** — ข้อมูลสกิลและหน้า Studio แท็บ "สกิล" ทำไว้แล้ว แต่ **ตัวเกมยังไม่ได้ใช้สกิล** (กดแถบสกิลแล้วยังไม่เกิดอะไร)
> เอกสารนี้ไว้ให้แก้ตัวเลข/กติกาได้ง่าย ก่อนจะลงมือเขียนระบบจริง · สูตรอื่นของเกมดู [`GAME_FORMULAS.md`](GAME_FORMULAS.md)
>
> ที่อยู่ของข้อมูล: ค่าตั้งต้น `src/skills.js` · ที่แก้ใน Studio เก็บใน `data/overrides.json` (ส่วน `skills`) · โครงฟิลด์/ช่วงค่า `SCHEMA.skills` ใน `src/overrides.js`

## 1. หลักการที่ตัดสินใจแล้ว

1. **ไม่มีอาชีพ ไม่มี Job Level** — ใครเรียนสกิลอะไรก็ได้ ความเก่งมาจากสเตตัส + อาวุธ + สกิลที่เลือกเรียน
2. **สกิลมี 2 แบบ**
   - **Active** — กดใช้ (ลงช่องสกิล 1–4 / คลิก) กิน SP มีคูลดาวน์
   - **Passive** — ติดตัวถาวร ตราบที่เรียนแล้ว ไม่กิน SP ไม่ต้องกด
3. **ได้สกิลมาจาก "สมุดสกิล" (Skill Book)** ที่สุ่มจากตู้กาชาด้วยเงิน
   - **ใช้สมุดเรียนสกิลได้ก็ต่อเมื่อยังไม่เคยเรียนสกิลนั้น** (เรียนแล้วใช้ซ้ำไม่ได้ ปุ่ม "ใช้" ถูกล็อก)
   - **สมุดขายได้** (ราคาตามความหายาก) — สมุดซ้ำที่ไม่ใช้ก็ขายเป็นเงินกลับคืน
   - เรียนแล้ว = ได้ตลอด (ไม่มีเลเวลสกิล ไม่มีรีเซ็ตสกิล — ตอนนี้)
   - **ไม่มีเลเวลขั้นต่ำ** — เรียนสกิลไหนก็ได้ทุกเลเวล (สมุดไม่มีเงื่อนไขเลเวล)
4. **เรียนได้ทุกสกิล แต่ "เลือกใช้" ได้ครั้งละ 4 สกิล** — มี 4 ช่อง (loadout) ใส่สกิลที่เรียนแล้วลงช่องเอง สลับได้ตลอด
   (ทั้ง Active และ Passive ต้องอยู่ในช่องถึงจะออกฤทธิ์ — ดูข้อ 6)
5. **SP** (มานา) เริ่มใช้พร้อมสกิล — SP สูงสุดมาจาก **INT + เลเวล** (ข้อ 4) ใช้ตามร่างข้อ 4 ไปก่อน

## 2. โครงข้อมูลของสกิลหนึ่งตัว

ทุกช่องแก้ได้ใน **Studio → สกิล** (ช่องที่แสดงจะเปลี่ยนตามประเภท/ผลลัพธ์)

| ฟิลด์ | ใช้กับ | ความหมาย |
|---|---|---|
| `name`, `desc` | ทั้งหมด | ชื่อ/คำอธิบาย |
| `kind` | ทั้งหมด | `active` กดใช้ · `passive` ติดตัว |
| `rarity` | ทั้งหมด | `common` `uncommon` `rare` `epic` (บอกสีและ ราคาสมุด/โอกาสกาชา ตามที่ตั้ง) |
| `weapon` | ทั้งหมด | อาวุธที่ต้องถือ: `any` · `melee` (มือเปล่า/กิ่งไม้/ดาบ) · `bow` · `staff` — Active: ไม่ถือก็ใช้ไม่ได้ · Passive: ไม่ถือก็ไม่ได้โบนัส |
| `target` | Active | `enemy` ศัตรู 1 ตัว · `enemy_area` ระเบิดรอบเป้าหมาย · `self_area` รอบตัว · `self` ตัวเอง |
| `effect` | Active | `damage` · `heal` · `buff` · `debuff` · `dash` |
| `spCost` | Active | SP ที่ใช้ |
| `cooldown` | Active | วินาทีก่อนใช้ซ้ำได้ |
| `range` | Active | ระยะใช้ (px) — 0 = ตามระยะอาวุธ (dash = ระยะพุ่ง) |
| `radius` | Active (area) | รัศมีพื้นที่ (px) |
| `power` | damage / heal | damage: **% ของ ATK ต่อฮิต** · heal: **% ของ Max HP** |
| `hits` | damage | จำนวนฮิต (ดาเมจคิดต่อฮิต) |
| `scalesWith` + `statCoef` | damage / heal | เพิ่ม `สเตตัส × statCoef` เข้าไปในพลัง (เช่น INT × 2) |
| `slowPct`, `stunSec` | damage / debuff | ผลข้างเคียงต่อศัตรูที่โดน |
| `duration` | buff / debuff | วินาทีที่ออกฤทธิ์ |
| `bonusAtkPct` `bonusDefPct` `bonusHpPct` `bonusAspdPct` `bonusCritPct` `bonusSpPct` `bonusMovePct` | passive / buff | โบนัส (%) — Passive ถาวร · Buff เฉพาะช่วง `duration` · ติดลบได้ (เช่น DEF −15%) · `bonusCritPct` = บวกเป็น "จุดเปอร์เซ็นต์" |
| `bookSellPrice` | ทั้งหมด | ทองที่ได้เมื่อขายสมุดเล่มนี้ |
| `gachaWeight` | ทั้งหมด | น้ำหนักในตู้กาชา (0 = ไม่ออก) |

ตัวอย่างสกิลหนึ่งตัว (ข้อมูลจริงใน `src/skills.js`):
```js
fire_bolt: { name: 'Fire Bolt (ลูกไฟ)', kind: 'active', rarity: 'common', target: 'enemy', weapon: 'staff',
  effect: 'damage', power: 180, hits: 1, scalesWith: 'int', statCoef: 2, spCost: 14, cooldown: 3,
  bookSellPrice: 100, gachaWeight: 30 }
```

## 3. สูตรที่วางไว้ (ยังไม่ได้เขียนโค้ด — ตัวเลขแก้ได้)

### 3.1 สกิลดาเมจ
ต่อ 1 ฮิต (ใช้ตัวสุ่ม/คริเหมือนการตีปกติ ดู GAME_FORMULAS ข้อ 5)
```
ฐาน      = ATK × (power / 100)  +  (สเตตัสที่เลือก × statCoef)
ดาเมจ    = max(1, ฐาน − DEF มอนสเตอร์)
ดาเมจ    = floor(ดาเมจ × สุ่ม 0.90–1.10)        ถ้าคริ → × 1.6
ดาเมจรวม = ดาเมจ × hits
```
- สกิลแบบพื้นที่ (`*_area`): โดนศัตรูทุกตัวที่อยู่ในรัศมี `radius` (คิดแยกรายตัว)
- สกิลที่ต้องใช้อาวุธ (`weapon`) แต่ถืออาวุธไม่ตรง → ใช้ไม่ได้ (ไม่หัก SP/คูลดาวน์)
- ระยะใช้ = `range` (0 → ระยะอาวุธที่ถืออยู่ ดู GAME_FORMULAS ข้อ 4)

### 3.2 สกิลฟื้น HP
```
ฟื้น = Max HP × (power / 100) + (สเตตัส × statCoef)        (ไม่เกิน Max HP)
```

### 3.3 บัฟ / ดีบัฟ / พุ่ง
- **บัฟ**: ใส่โบนัส `bonus*Pct` ให้ตัวเอง `duration` วินาที (ใช้ซ้ำขณะออกฤทธิ์อยู่ = รีเซ็ตเวลา ไม่ซ้อนทับ)
- **ดีบัฟ/ผลข้างเคียง**: `slowPct` ลดความเร็วเดินศัตรู · `stunSec` ทำให้ขยับ/ตีไม่ได้ (ศัตรูกำลังไล่ตีผู้เล่นอยู่ → หยุดตามเวลา)
- **พุ่ง**: เลื่อนตัวละครไปข้างหน้า `range` px (ชนกำแพง/วัตถุทึบแล้วหยุด)

### 3.4 โบนัสจากสกิล Passive + Buff (การนำไปรวมกับสูตรเดิม)
เฉพาะสกิลที่ **อยู่ในช่อง 4 ช่อง** (Passive) หรือกำลังออกฤทธิ์ (Buff) — รวมโบนัส % ของทุกสกิลที่ออกฤทธิ์อยู่ **บวกกัน** แล้วคูณทีเดียวหลังรวมค่าอื่นแล้ว:
```
ATK สุดท้าย   = ATK (สูตร GAME_FORMULAS ข้อ 2) × (1 + ΣbonusAtkPct / 100)
DEF สุดท้าย   = DEF × (1 + ΣbonusDefPct / 100)
Max HP สุดท้าย = Max HP × (1 + ΣbonusHpPct / 100)
ASPD สุดท้าย  = ASPD × (1 + ΣbonusAspdPct / 100)
Crit สุดท้าย  = Crit + ΣbonusCritPct / 100            (ยังติดเพดาน 75%)
Max SP สุดท้าย = Max SP × (1 + ΣbonusSpPct / 100)
ความเร็วเดิน   = ความเร็วเดิม × (1 + ΣbonusMovePct / 100)
```

## 4. SP (มานา) — ข้อเสนอเริ่มต้น (แก้ได้)

```
Max SP   = 30 + (เลเวล × 2) + (INT × 4)
ฟื้น SP  = 1 + (INT × 0.1)  ต่อวินาที   (ทั้งตอนสู้และไม่สู้)
```
- เกมตอนนี้มีแถบ SP เป็นช่องล็อก + ช่องยา SP ล็อก — จะเปิดใช้พร้อมสกิล
- ยา SP (ไอเทมใหม่) ฟื้นตามขนาด เช่น เล็ก/กลาง/ใหญ่ (ยังไม่ได้กำหนดตัวเลข)
- Auto: ตั้งใช้ยา SP อัตโนมัติเมื่อ SP ต่ำกว่า % (เหมือนยา HP) และตั้งให้ Auto ใช้สกิลไหนเป็นประจำได้ (ยังไม่ได้ออกแบบ)

## 5. สมุดสกิล (Skill Book) และตู้กาชา

**ไอเทมสมุด** (ไอเทมประเภท `skill_book` หนึ่งเล่มต่อหนึ่งสกิล)
- ชื่อ: "สมุดสกิล: ⟨ชื่อสกิล⟩" · ราคาขาย = `bookSellPrice` ของสกิลนั้น
- **ใช้สมุด** → เรียนสกิล และสมุดหายไป · ถ้าเรียนสกิลนั้นไปแล้ว ปุ่มใช้ถูกล็อก (ขายได้อย่างเดียว)
- เก็บในกระเป๋า ซ้อนได้ (หลายเล่มของสกิลเดียวกัน)

**ตู้กาชา**
- จ่ายด้วยเงิน มี 2 แบบ: **สุ่ม 1 ครั้ง** และ **แพ็ก 10 ครั้ง** (ส่วนลดเล็กน้อย)
- ราคา (ข้อเสนอเริ่มต้น แก้ได้): 1 ครั้ง = **500 Gold** · แพ็ก 10 = **4,500 Gold** (ลด 10%)
  - อ้างอิง: มูลค่าขายสมุดเฉลี่ยต่อ 1 สุ่ม ≈ **232 Gold** (คิดจากข้อมูลตั้งต้นในข้อ 7) — ถ้าอยากให้คุ้มขึ้น/แพงขึ้น ปรับราคากาชาหรือ `bookSellPrice`
- สุ่มได้ **สมุดสกิล 1 เล่มต่อครั้ง** (แพ็ก 10 = 10 เล่ม) โอกาสออก = `gachaWeight ÷ ผลรวม gachaWeight ทั้งหมด`
  (ตารางด้านล่างคือโอกาสต่อสกิลของข้อมูลตั้งต้น — Studio แสดงโอกาสสดตอนแก้ค่า)
- **ยังไม่มีระบบการันตี (pity)** และไม่มีของการันตีในแพ็ก 10 — ถ้าอยากได้ เพิ่มภายหลังได้
- (ภายหลัง) ราคากาชาจะเป็นค่าที่แก้ใน Studio ได้ ตอนนี้ยังเป็นค่าในโค้ด

## 6. ช่องสกิล (Loadout 4 ช่อง) และ Auto

- เรียนได้ไม่จำกัดจำนวน แต่ **เลือกใช้ได้ 4 สกิลพร้อมกัน** — 4 ช่องนี้คือแถบสกิลที่มีอยู่ (`HOTBAR_SIZE = 4` ใน `src/player.js`)
- ผู้เล่นเลือกสกิลที่เรียนแล้วลงช่องเอง จะเปลี่ยนเมื่อไรก็ได้ (ถ้าไม่ได้สู้อยู่/ไม่ติดคูลดาวน์ — รายละเอียดข้อจำกัดการสลับยังไม่กำหนด)
- **Active** ในช่อง = กดใช้ได้ (ช่อง 1–4) · **Passive** ในช่อง = โบนัสถาวรทำงาน (ไม่ต้องกด แต่กินช่อง 1 ช่อง)
  - ต้องการให้ Passive ไม่กินช่อง? เปลี่ยนกติกาได้ — บอกแล้วจะแก้เอกสารนี้
- หน้าต่าง "สกิลของฉัน": รายการที่เรียนแล้ว แยก Active/Passive แสดงรายละเอียด/SP/คูลดาวน์ + ปุ่มใส่/ถอดช่อง
- Auto: (ภายหลัง) ตั้งให้ใช้สกิลช่องไหนอัตโนมัติเมื่อพร้อม

## 8. แผนลงมือ (เมื่อพร้อม)

1. **ข้อมูล** ✅ ทำแล้ว — `src/skills.js` + Studio แท็บสกิล + กฎในเอกสารนี้
2. **SP** — เพิ่ม Max SP/ฟื้น SP ใน `src/player.js`, เปิดแถบ SP และช่องยา SP, ไอเทมยา SP
3. **เครื่องยนต์สกิล** — ตัวกลางตัวเดียวอ่านข้อมูลสกิล: เช็คอาวุธ/SP/คูลดาวน์ → ทำผล (ดาเมจ/ฟื้น/บัฟ/พุ่ง)
   - ดาเมจสกิลต้องผ่านการตรวจของ server (เพิ่มเพดานต่อฮิต/พื้นที่ ดูข้อจำกัดใน `GAME_FORMULAS.md` ข้อ 5 และข้อ 12)
4. **สมุดสกิล + กาชา + ขายสมุด** — ไอเทม `skill_book`, ตู้กาชา (ต่อยอดจากเมนูร้านค้า/กาชาเดิม), ปุ่มใช้/ขาย
5. **หน้าต่างสกิล + ลงช่อง** — รายการที่เรียน, ลากลงช่อง 1–4, แสดงคูลดาวน์
6. **โบนัส Passive/Buff** — รวมเข้ากับ getter ใน `Player` ตามข้อ 3.4
7. **ปรับสมดุล** — เทียบดาเมจสกิลกับมอนสเตอร์แต่ละแมพ

## 9. ตัดสินใจแล้ว / ยังเปิดอยู่

**ตัดสินใจแล้ว**
- กาชามีสุ่ม 1 ครั้ง + แพ็ก 10 ครั้ง · ยังไม่มีการันตี
- ไม่มีเลเวลขั้นต่ำในการเรียนสกิล เรียนได้ทุกสกิล · เลือกใช้ได้พร้อมกัน 4 สกิล
- SP ใช้สูตรร่างข้อ 4 ไปก่อน

**ยังเปิดอยู่ (แก้ได้ทีหลัง)**
- ราคากาชา 500 / 4,500 ตามข้อเสนอ ใช้ได้ไหม
